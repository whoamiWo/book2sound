# 与同类方案的对比

定位：**生成器**，不是播放器。产物交给 Apple Books / VLC / mpv / 任何支持 M4B 章节的播放器。

| 维度 | epub2m4b | 自制脚本（epub → txt → TTS） | 在线听书服务 | 桌面 GUI 转换器 |
| --- | --- | --- | --- | --- |
| 中文分章 | nav → nav+hybrid → outline → spine 四级策略 + 否决器 | 通常只按 spine 或固定长度 | 不需要用户处理 | 取决于软件，通常不可见 |
| 分章可信度 | `inspect --json` 给出每章 `start_key/end_key` 和被拒绝的策略原因 | 无 | 无 | 一般无 |
| 断点续跑 | 段级 SQLite + 内容寻址 FLAC 缓存，`kill -9` 也不丢已完成段 | 通常要重跑整本书 | 不适用 | 通常整本重来 |
| 换音色 | `synth_fingerprint` 包含 voice/model/rate；切回旧音色零合成 | 需要手动管理缓存 | 不适用 | 通常整本重合成 |
| 最小重算 | 改一章文本只重做该章受影响的段（e2e 验证） | 整本重跑 | 不适用 | 整本重跑 |
| 章节时间轴 | 整数采样数累加，ffprobe 校验，容差 150 ms | 手工拼接容易漂移 | 不适用 | 不保证 |
| TTS 后端 | 本地 Kokoro / 任意 OpenAI 兼容端点 / 静音 fake | 绑定单一引擎 | 绑定服务 | 绑定内置引擎 |
| 离线 | 是（Kokoro 本地） | 是 | 否 | 通常是 |
| 失败语义 | 退出码 0–5/130；段级重试与 `--allow-incomplete` | 自己实现 | 不适用 | 通常只有成功/失败 |
| 依赖 | Python + ffmpeg；核心 4 个 pip 包 | 视实现 | 浏览器 | 大型桌面应用 |
| 非目标 | 不做 OCR、不做 GUI、不做在线服务 | — | — | — |

## 什么时候不该用 epub2m4b

- **扫描版 EPUB**：没有文本层，本工具直接退出码 3，请先做 OCR。
- **需要实时流式播放**：本工具是"整本生成 → 交给播放器"，没有边下边播。
- **需要图形界面**：本项目是 CLI。
- **DRM 书籍**：不解 DRM，直接退出码 3。

## 与 PyPI 上的 `soundbook` 包的区别

PyPI 上的 `soundbook`（0.0.4，Erfan Samandarian）是一个**在线有声书下载/合并**工具，
CLI 是 `soundbook --url ...`，与本项目无关。为避免在用户机器上撞命令名，
本项目的发行名与可执行文件都叫 **`epub2m4b`**，只有 import 包沿用 `soundbook`（ADR-014）。
